## What we do

- **Desktop protection:** antivirus that runs on your own machine, with a quarantine you control.
- **Private networking:** encrypted DNS that fails closed, so lookups never leak in plain text.
- **Threat research:** we study real malware on macOS and Windows and turn it into readable rules.
- **Open source, always:** everything we ship is free software. Read the code and check our work.
